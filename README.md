# 环形燃料电池推进器 · 新构型

在线查看：https://yuao-188.github.io/fuelcell-propulsion-new-concept/

本仓库存放新构型交互模型的源码和 GitHub Pages 静态发布文件。本地几何版采用 Ø1000 mm、8 叶主风扇和略加长的直筒机匣；六级 Ø350/430/510/510/590/590 mm 电堆、各级 215 片示意排布。两处区间风扇舱各收至 160 mm，前进气到第 1 堆收至 300 mm；三台电机仅缩短轴向长度，直径不变。新鲜空气环道下壁在前段从 132 mm 半径平顺扩至第 1 堆附近的 202 mm，上下壁净距收至约 76–78 mm。

页面默认提供 6000 m、30 m/s、75 kW 条件下的温度显示：六级电堆等效平均温度、三台主/区间电机与环道定子的壳温估算，以及沿程粒子温度颜色。该结果依赖给定风量、功率和传热系数，是概念级条件热平衡，不是 CFD、局部热点、绕组温度或实际质量流量验证。

注意：Ø150 mm 电堆内孔的单圈 215 片在内缘仅有约 2.19 mm 周向节距。页面为避免可视化穿模，将示意片厚改为 1 mm；这不构成真实冷却气道或可制造性验证。给定有效径向高度恰好等于机械环带的全部径向高度，也未留密封/框架余量。后两台电机绘图外径 Ø148 mm，以免与 Ø150 mm 孔相交。

源码位于 `src/`。本地运行：`npm ci` 后执行 `npm run dev`；更新 GitHub Pages 根目录文件时，先运行 `npm run build`，再运行 `npm run prepare:pages`。

旧版站点继续保留在 https://yuao-188.github.io/fuelcell-propulsion-explorer/ 。
