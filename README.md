# 环形燃料电池推进器 · 三级构型

在线查看：https://yuao-188.github.io/fuelcell-propulsion-new-concept/

本仓库存放交互模型源码与 GitHub Pages 静态文件。当前为三级电堆：

| 级 | 有效径向长度 mm | 有效轴向长度 mm | 单片面积 cm² | 外径 mm |
| --- | --- | --- | --- | --- |
| 1 | 136 | 120 | 163.2 | 422 |
| 2 | 158 | 103 | 162.7 | 466 |
| 3 | 180 | 90 | 162.0 | 510 |

内孔沿用 Ø150 mm，每级沿用 215 片、示意片厚 1 mm。两端各保留 2 mm 端板，因此机械轴长为 124 / 107 / 94 mm。主推进风扇保持原有 Ø1000 mm、8 叶及前端几何。

两台区间增压风扇及对应电机已移除。保留入口新鲜空气环道外缘增压级；每级电堆前分别设置完整的环形引气结构，外壳与尾部随三级布局收缩。

温度模式按用户设定将三个电堆均显示为 55℃。气流颜色只表示不同流路。本次几何修改没有执行新的热平衡计算，旧六级方案的功率、风量、气温和电机壳温不用于新构型。

运行：`npm ci` 后执行 `npm run dev`。构建：`npm run build`。几何检查（Node 22.18+ 或 24）：`node scripts/verify-geometry.mjs`。更新 GitHub Pages 根目录：`npm run prepare:pages`，再提交生成的 `index.html` 与新资源文件。

本模型用于构型与流路可视化，片厚和保留间隙属于示意几何，不构成制造或热性能验证。
