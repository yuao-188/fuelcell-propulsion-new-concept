# 凸台电堆独立副本

页面路径：`/frustum-design/`。本页从2026-11-09的机匣与电机细节版复制，原`/new-design/`网页及其发布资源保持不变。

本次按用户示意图表现前大后小的中空环形圆台电堆。三级轴向长度分别300、250、220mm，两处级间距均100mm；用户确认机匣随电堆缩短，整机长1910mm。保留前端风扇、静叶与主电机。压气机外罩按用户红线形成整体圆滑渐缩轮廓，两级离心叶轮、背盘、静叶及独立小电机随局部壳体净空调整尺寸。

## 几何参数

下表尺寸单位为mm，前后方向沿推进系统轴线从风扇端指向尾部。

| 级别 | 轴向起止 | 轴向长度 | 前端内径/外径 | 后端内径/外径 |
|---|---|---:|---:|---:|
| 一级 | 740–1040 | 300 | 140 / 384 | 80 / 324 |
| 二级 | 1140–1390 | 250 | 176 / 424 | 116 / 364 |
| 三级 | 1490–1710 | 220 | 220 / 464 | 160 / 404 |

每级内外轮廓沿轴线同时收缩30mm半径；中截面外径保持原版354、394、434mm。用黑色层、银灰夹层和开缝突出圆台剖面的斜向条带。每级的20条示意叠层仅服务于外观表达，不代表实际单电池片数，也不沿用1357片计算。

二、三级可变引气罩仍延伸至前一级轴向中点，保留原有活动瓣片、套筒、作动环与连杆。级间导流罩改接圆台后端，后级中心隔离筒沿其内壁收缩。各类压力管路接口随局部半径定位：阴极进气位于内缘前侧，湿尾气位于内缘后侧，两套管路独立，删除旧的直连横管。蓝色空气主管缩至外径36、内径28mm。

外壳保留直筒与轻收缩尾段、分段法兰、检修盖、检查口、外线管和安装耳的风格；后部装配件随缩短后的机匣重新布置。尾段从1710延伸至1910mm。

## 电堆后端供氢与独立近景

供氢总管仍位于电堆中央孔内、蓝色空气主管外侧。每一级支路从总管引出，在电堆后方的冷却尾气收集空间内环绕一圈，再向中央孔收拢，从内缘后侧进入电堆；回氢接口位于内缘前侧下方。环绕段用有轴向进距的连续螺旋管表现，管壁与尾气空间隔开，供氢和尾气不混接。各接口用独立短接管表达，删除旧的外缘进回氢直连长管；回收连接通过后部气水分离器和循环泵完成。

模型仅表达管路与电堆接口，不用一根跨堆外管代替单电池内的反应流道。构建记录分别检查阴极进气与湿尾气的独立性，以及供氢环绕支路对回氢管路的隔离。

新增“一级电堆与管路”近景：只显示第一级电堆及该级空气、供氢、回氢、阴极尾气管段。电堆固定沿轴线半剖，各管路保持完整管壁；局部总管的边界显示真实空心管口。近景管路由总装实体裁取，作为专用显示对象导出，普通总装视图不显示这些重复展示件。

## 构建

`npm run build:frustum-design` 生成本副本的几何及网页。

`npm run prepare:frustum-design` 将编译结果复制至本目录发布资源，并确认原网页文件未变。

`scripts/frustum-design/`保存独立几何生成器，包括本副本的前端机械与压气机轮廓；本副本的几何记录写入`verification.json`。
