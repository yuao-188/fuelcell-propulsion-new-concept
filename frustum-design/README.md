# 凸台电堆独立副本

页面路径：`/frustum-design/`。本页从2026-11-09的机匣与电机细节版复制，原`/new-design/`网页及其发布资源保持不变。

本次按用户示意图表现前大后小的中空环形圆台电堆。三级轴向长度分别300、250、220mm，两处级间距均100mm；用户确认机匣随电堆缩短，整机长1910mm。前端风扇、静叶、主电机、两级离心压气机及其独立电机沿用原版。

## 几何参数

下表尺寸单位为mm，前后方向沿推进系统轴线从风扇端指向尾部。

| 级别 | 轴向起止 | 轴向长度 | 前端内径/外径 | 后端内径/外径 |
|---|---|---:|---:|---:|
| 一级 | 740–1040 | 300 | 140 / 384 | 80 / 324 |
| 二级 | 1140–1390 | 250 | 176 / 424 | 116 / 364 |
| 三级 | 1490–1710 | 220 | 220 / 464 | 160 / 404 |

每级内外轮廓沿轴线同时收缩30mm半径；中截面外径保持原版354、394、434mm。用黑色层、银灰夹层和开缝突出圆台剖面的斜向条带。每级的20条示意叠层仅服务于外观表达，不代表实际单电池片数，也不沿用1357片计算。

二、三级可变引气罩仍延伸至前一级轴向中点，保留原有活动瓣片、套筒、作动环与连杆。级间导流罩改接圆台后端，后级中心隔离筒沿其内壁收缩。各类压力管路和后端供氢接口随局部半径重新定位，阴极尾气干线收至中央孔内R32位置。供氢仍在蓝色空气主管外侧，进入各级后端面。

外壳保留直筒与轻收缩尾段、分段法兰、检修盖、检查口、外线管和安装耳的风格；后部装配件随缩短后的机匣重新布置。尾段从1710延伸至1910mm。

## 构建

`npm run build:frustum-design` 生成本副本的几何及网页。

`npm run prepare:frustum-design` 将编译结果复制至本目录发布资源，并确认原网页文件未变。

`scripts/frustum-design/`保存独立几何生成器；仅前端机械总成复用原有纯函数构建器和本副本参数。本副本的几何记录写入`verification.json`。
