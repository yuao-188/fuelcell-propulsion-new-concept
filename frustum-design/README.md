# 凸台电堆独立副本

页面路径：`/frustum-design/`。本页从2026-11-09的机匣与电机细节版复制，原`/new-design/`网页及其发布资源保持不变。

第四级按第三级等比例放大 10%。四级总成向前移动 40 mm，三级间距均为 100 mm，布局基准长 2212 mm。主电机前后盖各设 12 个圆角通风窗，窗后留有轴向贯通通道。

## 几何参数

下表尺寸单位为mm，前后方向沿推进系统轴线从风扇端指向尾部。

| 级别 | 轴向起止 | 轴向长度 | 前端内径/外径 | 后端内径/外径 |
|---|---|---:|---:|---:|
| 一级 | 700–1000 | 300 | 140 / 384 | 80 / 324 |
| 二级 | 1100–1350 | 250 | 176 / 424 | 116 / 364 |
| 三级 | 1450–1670 | 220 | 220 / 464 | 160 / 404 |
| 四级 | 1770–2012 | 242 | 242 / 510.4 | 176 / 444.4 |

前三个电堆的内外轮廓沿轴线同时收缩 30 mm 半径，第四级收缩 33 mm。黑色层、银灰夹层和开缝构成圆台剖面的斜向条带。每级用 20 条叠层作结构示意。

二、三、四级可变引气罩各自延伸至前一级轴向中点，可独立调节开度与偏转。级间导流罩与后级中心隔离筒接到各圆台后端。阴极进气位于内缘前侧，湿尾气位于内缘后侧，两套管路各自接入。蓝色空气主管保留压气机出口接口，一级支路从该接口后方取气，沿中心孔回折到靠前的堆体入口。

外壳止于 x = 380 mm 的前涵道后法兰。前部动力安装节由外承力环、六根斜向布置的直支臂和内承力环组成，分别与涵道后法兰和动力段接合。支臂采用窄迎风截面。蓝色主电机壳与金色压气机壳各有独立法兰，接合处带密封垫和贯穿紧固件。

四级电堆由独立安装节托住。三根直纵梁与发动机轴线平行，缩短各级外抱箍到纵梁之间的支臂，并在二级电堆后方接入较小的承力环。环外的三根中空安装管一根向上、两根向两侧斜下，端部带机体对接法兰。此安装节与前涵道机匣分离。

## 共轴压气机与主电机余热回路

两级离心叶轮由入口侧同一台电机经阶梯轴驱动。二级扩压静叶后方设置后轴承座和三根窄支臂。压气机通道近景标出共用轴和后支座。

金色主电机的中段夹套内有双圈环向冷却通道，两个端盖各保留十二个通风窗。冷却液进回管沿一侧纵梁敷设，经二级电堆后侧的预热器和循环泵闭合。预热器气侧接收已气化的氢气，通过隔壁从冷却液吸热，再送往中央分流点。网页可用“电机余热回路”切换显示夹套、管路及换热器。

## 电堆后端供氢与独立近景

新供氢入口设在二级承力环侧面。氢气预热后进入中央孔，在蓝色空气主管外侧分为前后两路，分别供一、二级和三、四级。各级供氢支路在本级后方的冷却尾气收集空间内环绕一圈，再从内缘后侧进入电堆。环绕段采用有轴向进距的连续螺旋管，管壁隔开供氢与尾气。回氢接口在内缘前侧，回氢经后部气水分离器和循环泵接入后段供氢支路。

模型仅表达管路与电堆接口，不用一根跨堆外管代替单电池内的反应流道。构建记录分别检查阴极进气与湿尾气的独立性，以及供氢环绕支路对回氢管路的隔离。

新增“一级电堆与管路”近景：只显示第一级电堆及该级空气、供氢、回氢、阴极尾气管段。电堆固定沿轴线半剖，各管路保持完整管壁；局部总管的边界显示真实空心管口。近景管路由总装实体裁取，作为专用显示对象导出，普通总装视图不显示这些重复展示件。

## 构建

`npm run build:frustum-design` 生成本副本的几何及网页。

`npm run prepare:frustum-design` 将编译结果复制至本目录发布资源，并确认原网页文件未变。

`scripts/frustum-design/`保存独立几何生成器，包括本副本的前端机械与压气机轮廓；本副本的几何记录写入`verification.json`。
