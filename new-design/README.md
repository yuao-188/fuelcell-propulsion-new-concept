## 组成与连接

- 涵道风扇接主电机前轴；蓝色引气段由独立的内、外薄壁筒组成。外筒内径 Φ330；内筒外径 Φ312、内径 Φ304，与 Φ300 电机留出 2 mm 径向间隙。两筒之间有 9 mm 径向环形引气道。用户明确要求内筒后端也开口，因此没有添加封闭尾罩；引气环道在后端进入压机入口空间。
- 最新用户示意要求缩短蓝段、突出黄色压机：在前端共同安装空间内，将蓝筒长从 360 调为 270 mm，压机长从 120 调为 210 mm；前端总长、主电机实体和后方电堆位置不变。这是新的展示布局，覆盖报告对应的轴向分段，不是新增的实机选型尺寸。
- 黄色增压机按报告的独立电驱离心式建立。安装段内依次为叶轮工作腔、收缩集流段和出口直颈；静止导流罩、入口眼、后弯叶片、背盘和外围扩压导叶分别建模。导流罩封住入口绕过叶轮外缘直达出口的宽环形旁路，转静件仍有正间隙。它是离心级的结构示意，不是已经完成气动设计的压机。
- 三级电堆分别由 3、4、4 块扇环模块组成，共 11 块。
- 中央蓝色空心主管末端开放；每级上下各有一根支管。蓝色内部通道经过模块间隙时形成可见的连接短管。
- 每级上下模块的后端面接绿色供氢，前端面接淡绿色回气。灰色歧管内衬跨越模块间隙，内部供回通道在不同轴向位置，每块模块内的阳极通道连接两者。
- 回气汇入第三级内腔、主管侧面的橙色循环泵，此位置已由用户再次确认。泵出口经短绿色管路接回供氢总管；新氢入口位于绿色总管尾端。
- 外壳包围整体构型；灰色整机内壳按最新标注向前延至 x=210。x=210–620 是严格等径的水平段，此后平滑扩张至末级之后，再收缩到尾端。主内壳为一体薄壁、两端开口，连接处保持连续斜率。图中红、黄线只定义曲线走向，不作为部件颜色。

剖切深度可在 0–100% 连续调节，50% 为中央半剖。剖切壳体、电堆及内部空气管道，保留风扇、电机与外接氢气管路便于观察。截面采用实体绕数模板缓冲封口，保留环孔和真实管腔。完整模式显示所有完整实体。可分别隐藏整机内外壳、引气外筒、引气内筒、黄色压气机外壳、电堆和三套管路；机壳紧固件随所属机壳一起显隐，不包含气流动画、温度或性能计算。

## 修改与生成

尺寸、级数及管径集中在 `parameters.mjs`。模型生成器用 Manifold 实体布尔运算先合并管件外表面，再减去贯通内腔；电堆接口也有实际切孔。`scripts/detailed-machinery.mjs` 建立扭转翼型、轮毂、端盖、双壁引气道与独立驱动离心叶轮；`scripts/detailed-stacks.mjs` 建立外围压紧框、夹紧杆和片层边缘；`scripts/detailed-shells.mjs` 建立整体机匣曲面及装配细节。每八片保留一道实体薄边，近距离材质补充 1.01 mm 片距，避免在浏览器载入数千套完整电池片。机匣采用低饱和金属蓝、香槟金与灰银材料；法兰、沉头紧固件及浅接缝具有实际座穴。PBR 材质由长条面光源环境形成连续反射，机加工表面细纹按屏幕尺寸滤波。

在仓库根目录执行：

```text
npm ci
npm run model:new-design
npm run dev:new-design
```

发布构建：

```text
npm run build:new-design
npm run prepare:new-design
```

新页的静态文件只写入 `new-design/`，原网页入口及原资源不变。生成的 GLB 供网页直接读取，浏览器不需要运行实体布尔计算。

## 验证

每次生成模型自动检查实体有效性、主风扇及增压机叶轮与轴的连接、11 个模块数量、候选实体对的精确相交、空气与氢气腔分离、各气腔贯通、模块与泵的连接，以及气腔是否被其他实体堵住。结果见 `verification.json`。实体检测容差用于浮点布尔运算，不是工程制造公差。

完整构建还会对导出的 GLB 执行 `scripts/verify-new-design-compressor.mjs`：重建前端实体，复查相交、蓝套完整内腔，以及经过压机入口眼、叶道、扩压区和出口的局部通路探针；确认原有绕过叶轮的宽旁路被导流罩截断。结果补充在 `compressorGeometry` 字段。该探针仅证明一条有限宽度的通路存在，不代表供气流量、压比或效率达标。

尺寸更新后必须重新生成并通过这些检查。本模型用于构型和连接关系展示，不是制造图或热流性能结论。

## 结构参考与待定项目

离心压气机的轴向入口、径向叶轮和扩压路径参考 [NASA 压气机说明](https://www.grc.nasa.gov/www/k-12/BGP/compress.html)。独立电驱离心式用于燃料电池供气，可参见 [三菱重工燃料电池电动压气机技术资料](https://www.mhi.com/technology/review/abstract-62-2-160)。这些资料用于辨认结构类型，不代表本模型已经选定厂商机型或验证效率。

AEF100 是涡扇发动机，本构型借鉴航空机匣与装配的外观语言，不复制未经公开确认的 AEF100 内部几何。当前 Φ36 空气主管是示意管径；应按报告的流量、压力、温度重新选径。主管尾端的开口、各支路阻力、压机性能图、轴承支承、密封及检修拆装也需要后续工程确定。实体不相交和局部空腔贯通只验证几何，不能代替这些设计。
