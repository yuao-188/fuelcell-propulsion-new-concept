# 新设计：三级模块化电堆与氢气循环

独立网页：<https://yuao-188.github.io/fuelcell-propulsion-new-concept/new-design/>

## 组成与连接

- 涵道风扇接主电机前轴；开口蓝色电机罩后接独立驱动的同轴增压机。
- 三级电堆分别由 3、4、4 块扇环模块组成，共 11 块。
- 中央蓝色空心主管末端开放；每级上下各有一根支管。蓝色内部通道经过模块间隙时形成可见的连接短管。
- 每级上下模块的后端面接绿色供氢，前端面接淡绿色回气。灰色歧管内衬跨越模块间隙，内部供回通道在不同轴向位置，每块模块内的阳极通道连接两者。
- 回气汇入第三级内腔、主管侧面的橙色循环泵，此位置已由用户再次确认。泵出口经短绿色管路接回供氢总管；新氢入口位于绿色总管尾端。
- 外壳包围整体构型；内壳轻微渐扩，在末级之后收缩，两端均开口。

剖切深度可在 0–100% 连续调节，50% 为中央半剖。剖切壳体、电堆及内部空气管道，保留风扇、电机与外接氢气管路便于观察。截面采用实体绕数模板缓冲封口，保留环孔和真实管腔。完整模式显示所有完整实体。可分别隐藏内外壳、电堆和三套管路，不包含气流动画、温度或性能计算。

## 修改与生成

尺寸、级数及管径集中在 `parameters.mjs`。模型生成器用 Manifold 实体布尔运算先合并管件外表面，再减去贯通内腔；电堆接口也有实际切孔。`scripts/detailed-machinery.mjs` 建立扭转翼型、轮毂、端盖与独立驱动离心叶轮；`scripts/detailed-stacks.mjs` 建立外围压紧框、夹紧杆和片层边缘。每八片保留一道实体薄边，近距离材质补充 1.01 mm 片距，避免在浏览器载入数千套完整电池片。金属与涂层分别采用 PBR 材质，并由长条面光源环境形成连续反射。

在仓库根目录执行：

```text
npm ci
npm run model:new-design
npm run dev:new-design
```

发布构建：

```text
npm run build:new-design
npm run prepare:new-design
```

新页的静态文件只写入 `new-design/`，原网页入口及原资源不变。生成的 GLB 供网页直接读取，浏览器不需要运行实体布尔计算。

## 验证

每次生成模型自动检查实体有效性、主风扇及增压机叶轮与轴的连接、11 个模块数量、候选实体对的精确相交、空气与氢气腔分离、各气腔贯通、模块与泵的连接，以及气腔是否被其他实体堵住。结果见 `verification.json`。实体检测容差用于浮点布尔运算，不是工程制造公差。

尺寸更新后必须重新生成并通过这些检查。本模型用于构型和连接关系展示，不是制造图或热流性能结论。
