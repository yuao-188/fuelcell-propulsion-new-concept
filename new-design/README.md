## 部件和连通关系

- 风扇16枚后掠扭转动叶、锥形前整流罩；弦线与轴线夹角从叶根约25°单调增至叶尖66°。锥罩尖端由x=50向前延长至x=0，基面仍在x=110、半径100，锥长由60增至110 mm；叶片、轮毂和轴的位置不变。18枚后静叶位于灰色内壳和外壳之间。
- 蓝色引气段为双层开口筒：外筒内径330，内筒直段内/外径304/312，前段环形间隙9。内筒在电机后方x=440起，用平滑曲线径向内收16 mm，至x=480尾口内/外径272/280；前后均开口，直段主电机净空约1.954 mm。
- 离心式压气机每级18片叶片，各有独立电机和短轴。叶片内缘沿锥形轮毂连续连接，与各级后背盘合成一个转子实体。一级叶片外半径162.8 mm、背盘143.8 mm；二级叶片外半径由114.8增至134.8 mm，背盘仍为114.8 mm，叶片外侧悬伸20 mm。两排扩压静叶各18片，位于x=552–567/619–629 mm，均与背盘后端留3 mm轴向间隔。级间回流静叶、两级静止罩盘和级间隔盘均已删除。当前展示开放的部件布局，不再使用此前隔盘封闭、外旁通封堵的验证结论。
- 删除入口六片曲面导叶，一级独立电机恢复x=484–510 mm和x=492处的三根细支杆。一级叶尖与机匣保守径向净空约2.15 mm；二级扩压静叶后端与后电机支杆前缘间隔2.6 mm。完整回转包络外扩0.8 mm后与固定件无交叠。
- 各模块有独立空气、湿尾气、供氢、回氢接口，每类11路。供氢绕至模块外圆面、径向向内接入；回氢仍接前端面。供氢通过外框和周向端板内的独立通道连接根部集流区，不跨模块分缝，也不切入片组。后侧供氢跨接段对准周向端板，避开片间轴向冷却出口。
- 阴极湿尾气汇入独立气水分离器，气体和独立排水管分别通向尾部。阳极回氢经过另一只分离器后进入第三级内腔的橙色循环泵，再通过三通接入供氢总管。
- 两只分离器具有真实内腔、交错挡板、集水杯和带阀排水管。排水布局为压差排水示意，未验证排水流量，不宣称重力自排。两套气路及排水不混接。
- 沿内壳布置少量绝缘线束、短分支、接线盒和卡箍；线束外形不代表已完成电气串并联、绝缘或载流设计。

所有管件先合并外部实体，再减去连通内腔，形成真实三通和弯头。接头端面对接；电堆根部使用明确座孔。冷却通道为实际空隙，材料纹理不会代替板片几何。

## 网页与生成

页面标题为“氢能燃料电池发动机”，压气机近景标题为“离心式压气机”。按用户标注删除副标题、部件辅助说明、压气机说明段、模块分组和尺寸展开区，保留部件显隐与操作控件。保持0–100%连续剖切、完整视图、侧视、正视和自由旋转缩放，以及片组/冷却缝、水管理近景。“压气机通道”近景显示两级叶片、背盘和扩压静叶，切换“叶轮与静叶”仅隐藏外机匣。片组快捷视角自动选择45%剖切以展示轴向槽，水管理选择37%以保留两侧分离器；整机默认仍为50%。剖切采用实体绕数模板缓冲封口，保留环孔、管腔和片间空隙。银灰机匣、金色机械部件、蓝色引气筒、石墨片组采用不同PBR表面；拉丝和喷砂细纹不改变几何。

集中尺寸见parameters.mjs，环向片组布局见scripts/stack-layout.mjs。生成器导出GLB、每个模块的接口清单和verification.json。

运行：npm run dev:new-design

完整检查和构建：npm run build:new-design

准备发布：npm run prepare:new-design

发布文件只写入new-design/。浏览器加载预生成GLB，不执行布尔运算。

Windows免安装桌面版复用同一构建输出，封装入口及说明见`desktop/README.md`。安装打包依赖后运行`node scripts/package-desktop.mjs`，将模型、网页资源和Electron运行环境一起打成ZIP。接收者完整解压后运行EXE，无需联网或安装Node.js。

## 验证范围

生成阶段验证实体有效性、44个模块接口、3813片实体、候选实体对精确相交、阴极/阳极腔体分离、两套完整回路连通以及管腔是否被实体堵塞。壳体同时核对风扇扫掠、堆壳间距和两壳间距。

导出后分别检查前端机械和片组：前端检查16动叶/18静叶、实际叶片66°叶尖角、两级各18片压气机叶片与独立驱动、叶根与背盘连接、一级叶片悬伸、背盘尺寸及后移扩压静叶间隙、其余三处盘面和级间回流静叶的移除、引气内壳逐站曲线和尾口开孔，以及结构中的入口至出口通路；片组检查实际片数、厚度、体积、逐级内缘间距、420 mm第二级内径、579.002 mm第二级外径、700 mm末级外径和内壳终点。3824条冷却通路的探针延伸到各级后端面之外9 mm，检查后侧供氢跨接段是否遮挡，探针直径随各级标称冷却缝设置。结果写入verification.json。浮点检测容差不代表制造公差。

采用包围盒初筛后再做精确实体检查，不能把圆环孔或管腔内的零件误判为穿模。几何验证不代替强度、气动、传热、密封或电气验证。
