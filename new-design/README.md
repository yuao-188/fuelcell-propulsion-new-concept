## 部件和连通关系

- 风扇12枚后掠扭转动叶、锥形前整流罩；弦线与轴线夹角从实际叶根约25.74°单调增至叶尖76°。18枚后静叶位于灰色内壳和外壳之间。
- 蓝色引气段为双层开口筒：外筒内径330，内筒内/外径304/312，环形间隙9。内筒前后均开口，主电机与内筒留2 mm径向间隙。
- 黄色压气机为两级离心结构，各级有独立电机和短轴。一级叶轮经静止扩压器及回流通道送入二级；二级出口进入中央蓝色主管。两个压气机电机的外形是装配示意，未进行功率密度或选型验证。
- 各模块有独立空气、湿尾气、供氢、回氢接口，每类11路。供氢绕至模块外圆面、径向向内接入；回氢仍接前端面。供氢通过外框和周向端板内的独立通道连接根部集流区，不跨模块分缝，也不切入片组。后侧供氢跨接段对准周向端板，避开片间轴向冷却出口。
- 阴极湿尾气汇入独立气水分离器，气体和独立排水管分别通向尾部。阳极回氢经过另一只分离器后进入第三级内腔的橙色循环泵，再通过三通接入供氢总管。
- 两只分离器具有真实内腔、交错挡板、集水杯和带阀排水管。排水布局为压差排水示意，未验证排水流量，不宣称重力自排。两套气路及排水不混接。
- 沿内壳布置少量绝缘线束、短分支、接线盒和卡箍；线束外形不代表已完成电气串并联、绝缘或载流设计。

所有管件先合并外部实体，再减去连通内腔，形成真实三通和弯头。接头端面对接；电堆根部使用明确座孔。冷却通道为实际空隙，材料纹理不会代替板片几何。

## 网页与生成

保持0–100%连续剖切、完整视图、侧视、正视和自由旋转缩放，以及片组/冷却缝、水管理近景和独立显隐。新增“压气机通道”近景：流道剖面显示两级叶轮、扩压与回流通道，切换“叶轮与静叶”后隐藏罩壳与隔盘，完整展示转动和静止部件。片组快捷视角自动选择45%剖切以展示轴向槽，水管理选择37%以保留两侧分离器；整机默认仍为50%。剖切采用实体绕数模板缓冲封口，保留环孔、管腔和片间空隙。银灰机匣、金色机械部件、蓝色引气筒、石墨片组采用不同PBR表面；拉丝和喷砂细纹不改变几何。

## 验证范围

生成阶段验证实体有效性、44个模块接口、3813片实体、候选实体对精确相交、阴极/阳极腔体分离、两套完整回路连通以及管腔是否被实体堵塞。壳体同时核对风扇扫掠、堆壳间距和两壳间距。

导出后分别检查前端机械和片组：前端检查12动叶/18静叶、实际叶片扭角、独立压机驱动、引气环道、级间回流、出口通路与旁路封堵；片组检查实际片数、厚度、体积、内缘间距、700 mm末级外径和内壳终点。3824条冷却通路的探针延伸到各级后端面之外9 mm，检查后侧供氢跨接段是否遮挡。结果写入verification.json。浮点检测容差不代表制造公差。

采用包围盒初筛后再做精确实体检查，不能把圆环孔或管腔内的零件误判为穿模。几何验证不代替强度、气动、传热、密封或电气验证。
