| 级别 | 电堆内径 | 电堆外径 | 径向宽 | 轴向长度 | 全级片数 | 轴向起止 |

| 二级 | 146 | 394 | 124 | 420 | 455 | 1231–1651 |
| 三级 | 190 | 434 | 122 | 393 | 591 | 1671–2064 |

每级为一个完整环形电堆，共1357片。用户确认采用分级片数之和，替代图片中不一致的1358片总数。板组厚0.281，标称内缘节距1.01；在精确内径上均匀排布后，实际内缘净缝分别约0.729156、0.727070、0.728987。保持各级给定内外径、片数和长度，不为凑标称节距放大内径。管路座孔仅占片组局部边缘。每级另设0.3mm外圆薄封边，含0.025mm座隙，占用总成尺寸以内的外缘0.325mm装配区，防止轴向冷却气从外缘漏入后级新气。该区域不再计为有效片组；四道窄边箍和局部封边均不封闭轴向冷却端面。

两处轴向级间距均20；用户明确选择保持该间距，因此排气收集罩采用短而陡的圆滑收缩，而非拉长锥段。整机长2264，片组长度1284，含级间隙1324。直段外壳内径1000，尾段从2064开始轻收缩，出口内径940.4。

## 结构和交互

- 保留16枚推进动叶、18枚后静叶与66°叶尖角。撤去长内壳，前静叶位置保留独立短支承环。
- 压气机总段由480延至740，两级各有独立小电机；增加小电机外壳筋条、端盖和可识别材质。
- 二、三级前设置各24瓣主瓣片与24片密封片的进气罩，带固定法兰、真实空心铰耳与销轴、作动环、六套伸缩执行杆和瓣片联动杆。
- 两级分别调节开度、上下偏转及左右偏转。偏转显示范围各±5°；三项控制共同更新瓣片、作动环与杆件，使用同一几何求解器，不将整个模型简单缩放。
- 一级冷却排气被收集进入二级中心隔离筒；二级排气与已通过中心筒的上游排气在其后汇集进入三级中心筒。新鲜冷却空气从外侧进入各级片组，隔壁分开新气与前级废气。末级后设置局部排气收集尾罩。
- 阴极空气主管、湿尾气、供氢、回氢每类各3路接口。供氢从外圆接入，外侧供回氢干线与可变机构错开。穿隔离罩处有一体密封套与对应座孔。
- 阴阳极两只气水分离器、阳极循环泵移到末级后部空间；两路独立排水和阴极尾气引至尾部。保留一束简洁线束。
- 连续剖切、完整视图、显隐和近景保留；新增二、三级进气罩近景。动态几何和剖切模板同步更新。

本页展示结构与机构动作。本次没有重算用户表中的温度、功率、流量或压力损失，也没有添加气流动画。

## 源文件与构建

- `parameters.mjs`：集中尺寸。
- `intake-kinematics.mjs`：Node与浏览器共用的瓣片机构几何求解器。
- `../scripts/annular-stacks.mjs`：1357片实体板组。
- `../scripts/compact-fluid-networks.mjs`：压力管路、分离器与循环泵。
- `../scripts/straight-shells.mjs`：直外壳与级间冷却排气隔离罩。
- `../scripts/build-variable-design.mjs`：总装、精确实体/管腔检查与GLB导出。
- `../scripts/verify-variable-design.mjs`：导出后的实体、片数、冷却通道和50组机构状态检查。

开发：`npm run dev:new-design`

生成、验证与构建：`npm run build:new-design`

准备GitHub Pages文件：`npm run prepare:new-design`，只写入`new-design/`。

验收记录写入`verification.json`。采用包围盒初筛后再作实体布尔相交，中心孔和管腔按真实空腔处理。导出验证重新读取Float32网格；逐级核对实际独立片数，并以1357条轴向探针检查中径冷却缝。机构检查记录实际采样的开度与偏转组合。浏览器另检验两级控制互不串改、剖切同步、错误日志及桌面/窄屏显示。
